# Crash Course

Crash Course is a small game developed for a game development exam. In Crash Course, the player controls a car from a top-down perspective while attempting to dodge enemy vehicles. If the player falls off of the map or touches an enemy car for 5 seconds, they lose.

## Prerequisites

To work on this project, you need to have the following software installed on your computer:

- Unity
- Git
- Visual Studio Code or different IDE

## Quick start

To start working on this project, you first need to clone this repository locally. You can do this with this command:

```
git clone https://github.com/Penguin-09/Crash-Course.git
```

After cloning the repository, open the project with unity. Clicking on any of the C# scripts opens it in your IDE of choice.

## Codebase best practices

Make sure to write enough comments while working on the code of this project. Any code should be easily understandable, even if the reader has never interacted with this project before.

When creating variables, make sure to name them with **camelCase**.
